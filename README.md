# OPC
OPC network

## 数据库约定

- 网站唯一的业务数据库是 MySQL `opc_platform`（下划线，不是 `opc-platform`）。本地后端配置和线上后端都连接此库；新增业务表、迁移和数据导入也以此库为目标，不另建业务数据库。
- 线上 `opc_platform` 中经过筛选的数据是本地政策、案例、高校等资料及账号、运行记录的同步来源。同步前备份目标库并核对库名，同步后核对表结构、记录数和公开接口；不要用本地旧资料覆盖线上筛选结果。
- 本地 `opc` 是另一套旧表结构；`opc_case_v4_test*_20260817` 是历史案例测试与备份库。它们不作为网站的数据源，也不直接合并到 `opc_platform`。
- `platform_sites` 目前只在本地 `opc_platform` 中，保存平台集合的 37 条资料。线上部署该模块时应在同一个 `opc_platform` 中执行 `deploy/sql/20261025_platform_sites*.sql`，不创建新库。

2026-10-25 本地从线上同步后的核验值：`opc_platform` 共 57 张表（线上 56 张，加本地 `platform_sites`），政策 114 条、案例 202 条、高校 106 条、平台 37 条。线上后续更新后，这些数量需要重新核对。
